# AdSales/Hub — Brand assets v2

Sistema visual operacional. Container laranja (#FF5A1F) é cor dominante. Wordmark Inter 600 com separador "/" técnico.

## Diferenças vs v1
- **Container laranja sólido** (era preto)
- **Seta branca** (era gradiente laranja)
- **Wordmark Inter 600** (era 500)
- **Separador "/"** (era "·")
- **Sem serif italic** na expressão da marca

## Snippet `<head>`

```html
<link rel="icon" href="/favicon.ico" sizes="any">
<link rel="icon" type="image/svg+xml" href="/brand-assets/svg/favicon.svg">
<link rel="apple-touch-icon" href="/brand-assets/apple-touch-icon.png">
<meta name="theme-color" content="#FF5A1F">
```

## Cores oficiais
| Token       | Hex      | Uso                           |
|-------------|----------|-------------------------------|
| Brasa       | #FF5A1F  | Container, CTA, dominante     |
| Brasa Dark  | #E64B14  | Hover, ênfase                 |
| Tinta       | #0E0E10  | Texto principal               |
| Tinta 2     | #2A2A2E  | Texto secundário              |
| Papel       | #FAFAF7  | Fundo                         |
| Papel 2     | #F2F1EC  | Cards                         |

## Tipografia
- **Inter 600** — wordmark, headlines técnicas, UI labels
- **Inter 700** — peso do separador "/"
- **Inter 400/500** — corpo
